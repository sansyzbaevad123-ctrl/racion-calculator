# Сайт «Калькулятор рациона и КБЖУ»

Исходный React-компонент из предоставленного файла находится в `src/App.tsx`. Подготовлен для React + Vite + Tailwind CSS + Lucide.

## Запуск на своём компьютере

1. Установите Node.js (версии 20.19+ или 22+) с сайта https://nodejs.org/.
2. Откройте терминал в папке `racion-site`.
3. Выполните:

   ```bash
   npm install
   npm run dev
   ```

4. Перейдите по адресу, который покажет Vite (обычно http://localhost:5173).

## Публикация сайта в интернете

### Способ A — Vercel

1. Создайте репозиторий GitHub и загрузите в него содержимое этой папки (не загружайте `node_modules`).
2. Зайдите на https://vercel.com/new и импортируйте репозиторий.
3. Framework: **Vite**; Build Command: **npm run build**; Output Directory: **dist**.
4. Нажмите Deploy. Появится публичная ссылка.

### Способ B — Netlify

1. В этой папке выполните `npm install` и `npm run build`.
2. Откройте https://app.netlify.com/drop.
3. Перетащите папку `dist` в браузер. Появится публичный адрес.

## Важно

- Приложение сейчас работает только в браузере, без сервера и базы данных.
- В исходном коде нет сохранения состояния: введённые изменения сбрасываются при перезагрузке страницы.
- Для учётных записей пользователей, истории по датам или синхронизации между устройствами потребуется серверная часть или облачный сервис.
